#### 📦 Featured

**[Exhibo Pro](https://github.com/ikokin/exhibo-pro)** — the sourcing notebook for trade exhibitions.
Walk a 100,000-booth fair like Canton Fair and by day three every supplier blurs together. Exhibo turns that chaos into a structured, searchable record — suppliers, findings, samples, business-card OCR — and then into an AI report. Shipped, in production, MIT-licensed so you can build on it.
